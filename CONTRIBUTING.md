# Contribuindo
### Testando e aprendendo a criar pasta "Contributing"

## 📌 Como contribuir
1. Faça um fork
2. Crie uma branch:
   git checkout -b minha-feature
3. Commit:
   git commit -m "feat: nova funcionalidade"
4. Push:
   git push origin minha-feature
5. Abra um Pull Request

## 🧪 Padrões
- Nome de variáveis em inglês
- Código limpo
- Seguir padrão MVC

## 📝 Commits
Usar padrão:
- feat: nova feature
- fix: correção
- docs: documentação
